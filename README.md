## 🌟 Descripción General

Este repositorio contiene la presentación técnica y comercial definitiva para el equipo de ventas y asesores de **ALFADEKOR**.
Diseñada con una arquitectura **100% standalone** (un único archivo HTML sin dependencias de red, fuentes ni librerías externas en tiempo de ejecución), integra microinteracciones táctiles, sonido procedural con Web Audio API, diseño responsivo 16:9 y renderizado visual ergonómico de alta gama.

## 🕹️ Controles de Navegación

- **Flechas ← / → o Espacio:** Navegación fluida de láminas.
- **Tecla F / Botón Pantalla Completa:** Modo presentación inmersiva.
- **Tecla G / Botón Cuadrícula:** Selector visual de las 30 diapositivas.
- **Tecla M / Botón Audio:** Silenciar o activar efectos sonoros.
- **Tecla H / Botón Ayuda:** Panel de atajos.
- **Táctil (Swipe):** Deslizar a la izquierda o derecha en móviles y tablets.

---

## 🛠️ Especificaciones Técnicas

- **Single-File Architecture:** 3.87 MB con 84 activos visuales incrustados en Base64.
- **100% Offline:** Funciona sin conexión a internet.
- **Procedural Audio:** Sonidos sintetizados en tiempo real mediante Web Audio API.
- **Responsive Viewport:** Auto-escalado automático a cualquier resolución conservando proporción 16:9.
